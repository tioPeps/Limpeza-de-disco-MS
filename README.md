# Limpeza de Disco — MULLER SOLUÇÕES

Programa para Windows que analisa o disco e libera espaço **com segurança**.

## Baixar

➡️ **[Baixar a versão mais recente](https://github.com/tioPeps/Limpeza-de-disco-MS/releases/latest)**: baixe o arquivo `.zip`, extraia e abra `Limpeza de Disco MULLER SOLUÇÕES.exe`. Não precisa instalar.

Depois disso, o próprio programa avisa quando houver uma versão nova e **pergunta antes de atualizar**.

> Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações › Executar assim mesmo**.

## Como ele protege seus arquivos

- A análise só **lê** o disco; nada é apagado sem você marcar e confirmar.
- **SEGURO APAGAR**: temporários, caches, lixeira e instaladores já usados.
- **REVISAR ANTES**: arquivos pessoais vão primeiro para uma quarentena, de onde dá para restaurar.
- **NÃO MEXER**: Windows, programas e jogos instalados, dados de aplicativos, outros usuários e arquivos de sistema nunca podem ser marcados.
- Cada atualização é **assinada digitalmente** pela MULLER SOLUÇÕES e conferida pelo programa antes de ser instalada.
- O programa só consulta o número da versão neste repositório; **nenhum dado seu é enviado**.
